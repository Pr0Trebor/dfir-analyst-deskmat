FILE ANALYSIS IOC / TRIAGE
Get-FileHash .\filename.ext -Algorithm SHA256
Calculate SHA256 hash
Format-Hex -Path .\filename.ext -Count 16
Determine the actual file type from the file header / magic bytes
Get-Item .\filename.ext | Format-List *
Inspect file metadata, timestamps and attributes
Get-AuthenticodeSignature .\filename.ext
Check Authenticode signature and signer status
Get-Content .\filename.ext -AsByteStream -TotalCount 32
Read the first bytes of a file (PowerShell 7+; on 5.1 use -Encoding Byte)
certutil -dump .\filename.ext
Dump the file as structured ASN.1 data (mainly for certificates / signed blobs, not a general hex viewer)
certutil -hashfile .\filename.ext SHA256
Calculate SHA256 hash from CMD
strings.exe -n 6 .\filename.ext
Extract printable strings from a suspicious file
Get-ChildItem .\filename.ext -Force
Inspect file presence and hidden/system attributes
Get-Item .\filename.ext -Stream *
List NTFS Alternate Data Streams
PROCESS INVESTIGATION PID / PPID
Get-CimInstance Win32_Process |
    Select-Object ProcessId,ParentProcessId,Name,CommandLine
Review process → PID → PPID → executable → command line
Get-Process -Id <PID> | Select-Object *
Inspect detailed properties of a specific process
Get-CimInstance Win32_Process |
    Where-Object ProcessId -eq <PID> |
    Select-Object *
Inspect detailed WMI process information for a PID
Get-Process -Id <PID> | Select-Object Id,ProcessName,Path,StartTime
Quickly identify executable path and process start time
tasklist /v /fi "PID eq <PID>"
Quick CMD lookup for a specific PID
DFIR tip: A suspicious process is often more interesting when its PPID, command line, executable path and start time are considered together.

Inspect current-user Run persistence from CMD

    Select-Object Name,State,StartMode,PathName

Why it matters: Run keys are a common persistence location. Look for unusual executable paths, scripts, temporary directories, user-writable locations and recently introduced values.
